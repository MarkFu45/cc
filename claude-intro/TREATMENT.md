# 《从一句话开始》— Claude 介绍短片 · Treatment

- 风格：Lemo-Opuscar「暗色科技发布 Dark Tech Keynote」(`dark-keynote`)
- 提示词参考：awesome-opus5-5-videos 中 @0xnicc0《Product Launch Motion Film》的结构语法——**一个形状讲完整个故事**：输入框变按钮、变进度环、变窗口、再变回输入框；物体变形代替剪辑；最后一帧 = 第一帧；全部画面是 `render(t)` 的纯函数，弹簧用闭式解。
- 规格：1920×1080，24 fps，约 56 s，中文旁白（edge-tts 云希）+ 烧录字幕 + `.srt`，−14 LUFS。
- 强调色：暖珊瑚橙 `#FF7A45`（只给 Claude 本身：光标、发送、确认、关键数字）。问题色：红 `#FF4D5E`，只在"混乱"段落出现，转折后不再回来。
- 不使用 Anthropic / Claude 官方标志；品牌记号是一个原创的珊瑚色闪烁光标。"Claude"只以 Inter 字体的文字出现。

## 1. 三个候选结构

1. **倒数清单**：一张"今天要做的事"清单，Claude 一项项勾掉，最后一项是"做一部介绍自己的片子"。——清晰，但像待办 App 广告，Claude 的"对话"本质不明显。
2. **左右分屏**：左边一个人独自面对文档、代码、数据，越堆越多；右边同样的事交给 Claude，提前完成。——对比强，但两边同时读太累，56 秒里字幕和画面会打架。
3. **一个形状的单镜头旅程**（选用）：一切从一个闪烁的光标开始。混乱的工作把它淹没 → 时间冻结 → 你在输入框里说一句话 → 输入框变成发送按钮、变成思考环、长出能力卡片、变成窗口 → 最后揭示"这部片子本身也是 Claude 用代码写的"→ 窗口收回成输入框，光标继续闪烁。

选 3 的理由：Claude 的入口就是"一个输入框 + 一句话"，让同一个形状承担全部叙事，正好是 @0xnicc0 提示词的核心语法，也符合风格里"活体元素 / 光标即品牌"的原生手法；结尾回到开头的输入框，形成首尾呼应。

## 2. Logline 与弧线

**Logline**：工作像潮水一样涌来，一个闪烁的光标等你开口——说一句话，Claude 就把混乱变成秩序，而你正在看的这部片子，就是它写出来的。

- **Setup**（0–8 s）：文件、代码、表格、消息、红色未读角标，按规则生成、越堆越快。
- **Turn**（8–20 s）：冻结、静音；推进到画面中央唯一还活着的东西——光标。输入一句话，按下发送。所有碎片沿弯曲轨迹飞入整齐的网格，红色消失。
- **Development**（20–39 s）：思考环展开成四张能力卡片：写作、编程、分析、看图；再收束成"会动手的助手"——一步步调用工具把事做完。
- **Reveal**（39–47 s）：数字从字形噪声里锁定："700+"，社区用 Claude 写代码生成的视频；镜头拉出——"就像这一部"，画面缩进一个代码窗口，`render(t)` 在跑。
- **Ending**（47–56 s）：窗口收回为空输入框，"Claude"被光扫亮，下面一行"想做的事，从一句话开始"。光标闪两下，熄灭成一个点。

## 3. 参照（只学语法）

- **学**：发布会的"一屏一句"、巨大数字独占一屏；软件发布片的 1 px 线、网格吸附、单一强调色；Steve Reich 式的加法过程音乐（每小节加一个音）。@0xnicc0 提示词的"形状接力、无交叉淡化、每拍有事发生"。
- **不学**：任何真实品牌的界面、字体、系统控件、旋律、Logo；不画真实操作系统窗口按钮；不放 Anthropic 官方标志。

## 6. 配乐地图

- 96 BPM，D 多利亚调式（D E F G A B C）。合成音色：马林巴（FM/加法合成）、颤音琴、钢片琴、柔和铺底 pad、低频正弦脉冲；全部 numpy 合成，无采样下载。
- 过程：**加法构建**——第 1 段只有失谐的散乱"通知声"（混乱家族，随机声像，±30 音分）；转折后马林巴每小节加一个音，直到能力段形成完整的 8 音循环；数字段减到只剩 pad + 正弦脉冲；结尾所有声部落到一个 Dm9 和弦上，延音消散。
- 段落：S1 混乱（无调性通知 + 风扇嗡鸣，渐强）→ S2 冻结（数字零）→ S3 光标/打字（只有 pad 与按键）→ S4 网格（马林巴加法 + 落位闪烁）→ S5–S6 能力与流程（完整循环 + 颤音琴旋律 + 摇铃）→ S7 数字（减法，近静音进入）→ S8–S9 窗口与结尾（终止和弦 + 钢片琴回声）。

## 8. 字幕与标题设计

- 旁白字幕 = UI 组件：底部居中的深色半透明药丸 toast，1 px 亮边，左侧珊瑚色"说话中"小圆点，Noto Sans SC 500 约 40 px；上浮 + 淡入 0.16 s。停留 ≥ max(1.8 s, 语音 + 0.6 s)。
- 光标打出的"帮我把这些理清楚"本身就是字幕，不重复烧录（只进 .srt）。
- 一屏一句标题，Noto Sans SC 700；数字用 Inter Tight 600，字距 −4.5 %；标签用 JetBrains Mono。
- 巨大数字那一屏没有字幕压在上面（旁白字幕在数字落定后才出现在下方安全区）。

## 11. 成片说明（制作后补记）

- 成片 55.0 s；实际时间点以 `film.js` 中的 `K` / `VO` 为准（上面的节拍表是制作前的计划，旁白定长后整体微调过）。
- 与本风格示范片《Room to Think》对照（DIRECTOR.md §11，六项中至少四项不同）：开场不同（我们从生成式信息风暴开场，示范片从安静的光标打字开场）；签名镜头不同（我们是"整部片缩进自己的源码窗口"，示范片是网格吸附）；镜头路径不同（无持续对数拉远，改为横移卡片、流程图横移和窗口拉出）；配乐形态不同（加法构建 → 减法 → Dm9 终止，示范片是相位漂移）。相同之处：冻结 + 数字静音、巨大数字独占一屏——都是该风格的原生手法。
- 人声：edge-tts 云希，语速 −4%；faster-whisper small 回听检查，l8 的"一部/一步"为同音误识别，已人工确认。
